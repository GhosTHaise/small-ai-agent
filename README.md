## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/small-ai-agent.git
cd small-ai-agent
```

### 2. Create a virtual environment

```bash
python -m venv venv
source venv/bin/activate  # On macOS/Linux
venv\Scripts\activate     # On Windows
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the agent

```bash
python agent.py
```

## 🛠️ Requirements

* Python 3.9+
